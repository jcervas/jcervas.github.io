The placement a solver returns is a good default, not a judgment. This moves states and labels by hand: drag a state and its cells go with it, drag a label and it moves alone. Every feature carries the state it belongs to, so that grouping is all the handle needs to be — and what you save is the same flat GeoJSON that went in.
