Change in U.S. House apportionment

Every state is carved into as many equal-area cells as it held at its peak across the two censuses, so each cell is the same size nationally and a state that lost a seat simply has one cell more than it now needs. Click a state to zoom. Which cell is marked is presentational: a seat is apportioned to a state, not to a place inside it.
