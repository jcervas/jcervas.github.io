# Course Materials

Syllabi, outlines, and assignment handouts, one folder per academic year. These
were previously the separate `jcervas/teaching` repo; they now live here in the
site repo and are published as static files under `/teaching/<year>/`.

Note that `/teaching/` itself and `/teaching/<course-name>/` are generated by
Jekyll — from `teaching.html` and the `_courses` collection respectively. The
year folders below sit alongside those pages rather than replacing them.
