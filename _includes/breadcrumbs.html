{%- comment -%} Breadcrumb trail. Included once by _layouts/default.html, so every page that uses a layout gets one — nothing to add per page. The trail is walked up from the page URL, so /maps/cartogram-method/browser/ becomes Home / Maps / Cartogram method / Solving it in the browser. Front matter a page can set: breadcrumb: "Short title" label for this page in its own trail and in the trail of anything beneath it (defaults to the page title, which is often too long) breadcrumb_parent: /some/url/ parent to use instead of the one in the URL, for pages that live under a path with no index page of its own (the /maps/* pages) breadcrumbs: false no trail on this page Labels for URLs that have no page of their own live in _data/breadcrumbs.yml. An ancestor with no page behind it is rendered as plain text, not a dead link. {%- endcomment -%} {%- if page.url != "/" and page.breadcrumbs != false -%} {%- comment -%} Every addressable page, so ancestors can be titled and linked. {%- endcomment -%} {%- assign bc_docs = site.pages -%} {%- for bc_c in site.collections -%} {%- assign bc_docs = bc_docs | concat: bc_c.docs -%} {%- endfor -%} {%- comment -%} Walk up to the root, following breadcrumb_parent where it is set and the URL where it is not. Ancestors are prepended, so the trail comes out outermost first.
